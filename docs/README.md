# docs/

- `config.schema.json` — JSON Schema for `model.Config`, generated by
  `make schema` (`daemon/cmd/schemagen`, via `daemon/internal/schema` —
  see `specs/adr/0005-schema-generation-via-invopop.md` for why the
  generator is a separate command rather than a `cmd/knobd` flag).
  Committed and gated in CI: a stale schema fails the build (see
  `.github/workflows/ci.yml`'s "schema up to date" step). Regenerate it
  after any change to `daemon/internal/model`'s JSON shape.
- `openapi.json` — OpenAPI spec for the daemon's local HTTP API, not
  generated yet: it needs `daemon/internal/api` to actually have routes
  first (M04). Still gitignored until then. Once it exists, it feeds
  `ui/`'s TypeScript client generation (M07) the same way
  `config.schema.json` feeds `ui/src/types/config.ts` today.

`ui/src/types/config.ts` is generated from `config.schema.json` by
`npm run codegen` (`ui/`) — see that file's header comment. It is
committed and gated in CI the same way.
