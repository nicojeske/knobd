# docs/

- `config.schema.json` — JSON Schema for `model.Config`, generated by
  `make schema` (`daemon/cmd/schemagen`, via `daemon/internal/schema` —
  see `specs/adr/0005-schema-generation-via-invopop.md` for why the
  generator is a separate command rather than a `cmd/knobd` flag).
  Committed and gated in CI: a stale schema fails the build (see
  `.github/workflows/ci.yml`'s "schema up to date" step). Regenerate it
  after any change to `daemon/internal/model`'s JSON shape.
- `openapi.json` — OpenAPI 3.1 spec for the daemon's local HTTP API,
  generated by `make schema` (`daemon/cmd/schemagen -kind openapi`, via
  a small local document model in `daemon/internal/schema/openapi.go`
  — no external OpenAPI library; see `specs/adr/0005-schema-generation-
  via-invopop.md`). Committed and gated in CI (M07), the same way as
  `config.schema.json`. Feeds `ui/src/types/api.ts` via
  `openapi-typescript`.
- `device-layout.json` — per-`ControlKind` index ranges and the
  gesture-validity matrix (`model.ControlIndexRange`,
  `ControlKind.SupportsGesture`), generated by
  `daemon/cmd/schemagen -kind device-layout` (M07). Committed and
  gated in CI. Feeds `ui/src/types/device-layout.ts` via
  `json-schema-to-typescript`, so the visual panel and binding editor
  don't hand-duplicate the hardware's index ranges and gesture matrix.

**Two generators, two files, don't cross the streams:** `Config` and
its nested types come from `config.schema.json` →
`ui/src/types/config.ts` only. Everything else the API surfaces —
`State`, `AudioGraph`, `Capabilities`, `ErrorResponse`, the learn/event
payloads — comes from `openapi.json` → `ui/src/types/api.ts` only.
`ui/src/api/client.ts` imports `Config` from the former and everything
else from the latter; `openapi.json` `$ref`s the config schema for
`PUT /config`'s body rather than inlining a second copy of `Config`.

`ui/src/types/config.ts`, `ui/src/types/api.ts`, and
`ui/src/types/device-layout.ts` are generated from the three files
above by `npm run codegen` (`ui/`) — see `ui/src/api/client.ts`'s
header comment. All three are committed and gated in CI.
