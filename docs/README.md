# docs/

Generated artifacts, not checked in (see `.gitignore`):

- `config.schema.json` — JSON Schema for `model.Config`, generated by
  `make schema`. TODO(M01 remainder): the generator itself
  (`daemon/internal/config`'s schema emission) is not implemented yet —
  producing a correct JSON Schema for a Go tagged-union type
  (`model.Action`) by reflection is nontrivial enough to warrant its own
  pass rather than rushing it into this scaffolding session; see
  `specs/milestones/M01-foundations.md`'s open items.
- `openapi.json` — OpenAPI spec for the daemon's local HTTP API,
  generated once `daemon/internal/api` actually has routes (M04), used
  by `ui/`'s TypeScript client generation (M07).

Until both exist, `ui/src/types/config.ts` is a hand-maintained mirror
of `daemon/internal/model` — see that file's header comment.
